📊 Data Analysis and Visualization

📌 Project Overview

This project demonstrates practical applications of Data Analysis and Visualization using Python and its popular data science libraries. It covers data cleaning, numerical operations, statistical visualization, and interactive chart creation.

This project was developed as part of my learning journey in Data Science and Machine Learning.

🎯 Project Objectives

- Practice data cleaning and preprocessing using Pandas.
- Perform numerical operations using NumPy.
- Create charts and visualizations using Matplotlib.
- Explore statistical relationships using Seaborn.
- Build interactive visualizations using Plotly Express.
- Improve practical Python programming and data analysis skills.

🛠️ Technologies and Libraries

- Python — Programming language
- Pandas — Data manipulation and cleaning
- NumPy — Numerical computing
- Matplotlib — Data visualization
- Seaborn — Statistical visualization
- Plotly Express — Interactive charts
- Google Colab — Cloud-based notebook environment

📂 Project Contents

1. Employee Data Cleaning

- Create a Pandas DataFrame.
- Identify missing values in each column.
- Replace missing salary values with the mean.
- Replace missing age values with the median.
- Remove rows with missing department values.
- Calculate average salary by department using "groupby()".

2. Market Share and Distribution

- Create a pie chart showing mobile brand market shares.
- Display brand labels and percentage values.
- Highlight the largest slice using an exploded pie chart.
- Generate a histogram with 20 bins.
- Save the visualization as "market.png".

3. Iris Dataset Visualization

- Load the Iris dataset using Seaborn.
- Create a scatter plot of sepal length versus petal length.
- Visualize correlations using an annotated heatmap.
- Create an interactive box plot of petal width by species.
- Identify the strongest positive correlation between numerical features.
